# Personalized Feed Recommendation Service (FastAPI + CatBoost)

Этот проект — одна из частей финального проекта на курсе "Инженер машинного обучения" от Karpov.Courses. В нем реализован сервис персональных рекомендация постов для пользователей.

## Функционал проекта

Проект включает:

- вычисление пользовательских и постовых фичей (feature engineering)
- загрузку фичей в базу данных PostgreSQL
- обучение модели CatBoost для ранжирования постов
- разработку FastAPI сервиса для выдачи рекомендаций
- эндпоинт, который возвращает **топ-5 постов** для каждого пользователя

---

## Модель

Используется **CatBoostClassifier**, обученный на:

- поведенческих фичах пользователей
- статистике взаимодействий с постами
- текстовых фичах (длина текста, текстовая разнообразность)
- OHE-кодировании тем (`topic`)
- CTR постов по последнему 1M просмотров
- CTR пользователей
- User-topic CTR по каждой теме

Итоговая метрика HitRate@5 ? **0.55+** после улучшений (в ноутбуке значение метрики около 0.45, но LMS курса тестировала 2000 запросах, получилось значение метрики 0.602)

Модель сохранена в файл: `catboost_model.cbm`

## Как работает сервис

### Эндпоинт: GET /post/recommendations/

### Параметры:

| Параметр | Тип        | Описание                           |
|---------|------------|-------------------------------------|
| id      | int        | user_id для рекомендаций            |
| time    | datetime   | текущее время                       |
| limit   | int        | количество возвращаемых постов (5)  |

### Пример запроса

```python
import requests
from datetime import datetime

params = {
    "id": 203,
    "time": datetime(2020, 5, 17),
    "limit": 5
}

resp = requests.get("http://127.0.0.1:8000/post/recommendations/", params=params)
print(resp.json())
```

### Пример ответа
```json
[
  {
    "id": 12345,
    "text": "Some post text...",
    "topic": "sport"
  },
  ...
]
```
